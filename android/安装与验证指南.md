# Survolocking 安卓端 · 安装与验证指南（第一版 / Debug）

适用对象：想在真机上跑通第一版、验证「骚扰电话拦截 + 云端联动」的开发者/测试人员。
构建产物：`android/app/build/outputs/apk/debug/app-debug.apk`（debug 签名，无需自己配密钥即可装）。

> 包内 API 地址已烧录为 `https://survoid.top/sl`，直连线上服务端，无需改代码。

---

## 一、本地构建（命令行，无需 Android Studio）

本机已在 **F 盘**搭好免管理员命令行工具链，重构建只需三步：

```bat
cd /d F:\WorkBuddyDefault\2026-09-02-04-13-26\survolocking\android
set ANDROID_HOME=F:\Android\Sdk
set JAVA_HOME=F:\Android\jdk
set GRADLE_USER_HOME=F:\Android\.gradle
gradlew assembleDebug --no-daemon
```

产物出现在 `app\build\outputs\apk\debug\app-debug.apk`。

环境变量（`ANDROID_HOME` / `JAVA_HOME` / `GRADLE_USER_HOME` / `ANDROID_SDK_ROOT`）已写入系统用户变量，
新开 PowerShell/CMD 一般可直接 `gradlew`，无需每次 set。

## 二、安装到手机

### 方式 A：USB 线 + adb（推荐，最快）
1. 手机「设置 → 关于手机 → 连续点版本号」打开开发者选项。
2. 开发者选项里开启 **USB 调试**（部分机型还需「USB 安装」「一律允许」）。
3. 数据线连电脑，手机弹窗选「传输文件 / 允许 USB 调试」。
4. 电脑执行：
   ```bat
   F:\Android\Sdk\platform-tools\adb.exe install -r F:\WorkBuddyDefault\2026-09-02-04-13-26\survolocking\android\app\build\outputs\apk\debug\app-debug.apk
   ```
   `-r` 表示覆盖安装。看到 `Success` 即完成。

### 方式 B：手动传包安装
把 `app-debug.apk` 拷到手机存储，用文件管理器打开 → 按提示安装。
首次会要求「允许安装未知来源应用」，授权一次即可。

## 三、首次使用与权限（关键，否则拦截不生效）

1. 打开 App。
2. **设为默认拦截应用**（拦截生效的前提）：
   「设置 → 应用 → 默认应用 → 来电识别与骚扰拦截」→ 选择 **Survolocking**。
   不设置这一步，系统不会把来电交给本 App 判定。
3. 在 App 内点「授权通讯录」等按钮，授予：
   - 读取通讯录（白名单，避免误拦熟人）
   - 读取通话记录 / 电话状态（微行为分析用）
   - 通知权限（错过的来电提醒、标记快捷按钮）
4. 用手机号登录：目前 dev 模式下**验证码会直接回显在输入框**，点发送即可看到，填回即可登录。
   正式环境走阿里云短信（签名「恒创联众」、模板 `100001`）。

## 四、验证云端链路

登录后 App 会向 `https://survoid.top/sl` 发请求，验证方式：

- **健康检查（云端可达性）**：浏览器/手机访问
  `https://survoid.top/sl/health` 应返回
  `{"status":"ok","env":"prod","db":"mysql","cache":"memory","deepseek":true,"qiling":true}`。
- **登录联调**：App 登录成功 → 本地缓存服务端下发的号码哈希盐 → 首通来电即用真盐哈希。
- **规则同步**：App 后台会拉取 `GET /api/rules/sync`，把云端灰/黑规则落到本地 SQLite。
- **日志上传**：接听/未接的通话行为进入上传队列，联网后 `POST /api/logs/upload` 上报。

## 五、真机测试骚扰拦截流程

1. 用第二部手机（或网络电话）拨打本机。
2. 系统把号码交给 Survolocking 判定：
   - **拦截（BLOCK）**：来电被直接拒接，通话记录保留（便于事后核对）。
   - **静音（SILENCE）**：API 33+ 会静音响铃。
   - **警示（WARN）/ 放行（ALLOW）**：正常接通。
3. 未拦截的通话结束后，通知栏出现「骚扰 / 客户」快捷标记按钮，点选即回传 `markCall`，
   反哺分析与家庭共享库。

> 判定完全在**本地四层引擎**完成（<200ms），仅把号码哈希与行为日志出网，原始号码永不出端。

## 六、常见问题

| 现象 | 排查 |
|------|------|
| 来电没被拦截 | 没设为默认拦截应用（第三步第 2 条）；或号码在通讯录白名单 |
| 安装失败「解析错误」 | 旧版残留，用 `adb install -r` 覆盖；或手机未开启未知来源 |
| 登录一直转圈 | 检查手机能否访问 `survoid.top/sl/health`；公司网络/大陆外可能受 DNS 影响 |
| 日志不上传 | 检查通知/网络权限；队列会在有网时自动补传 |
| adb 找不到设备 | `adb devices` 为空 → 重插线、重开 USB 调试、装手机驱动 |

## 七、后续（非本机可完成的部分）

- **Android Studio GUI**：图形安装器需管理员权限，自动化环境装不了。官方包已留
  `F:\AndroidStudio\installer.exe`，请右键「以管理员身份运行」、目录填 `F:\AndroidStudio`。
- **正式发布包（release）**：需自备签名密钥（`keytool` 生成 jks），在
  `android/app/build.gradle.kts` 配 `signingConfigs`，再 `gradlew assembleRelease`。
  当前 `API_BASE` 走 `build.gradle.kts` 默认值，如需切环境可传 `-PapiBase=https://...`。
- **iOS 端**：需 macOS + Xcode，本 Windows 环境无法构建；其 `baseURL` 已就位为
  `https://survoid.top/sl`，到 Mac 上 `./build` 即可。
